# Spec Delta

## Purpose

更新设置页关于区，让用户知道运动记录仍只存本机，地点与天气随记录保存，查询会联网但坐标不会被保存。

## MODIFIED Requirements

### Requirement: 关于分组声明品牌与本机属性

设置页底部 SHALL 显示「行迹 XINGJI · 1.0.0」与「记录仅存本机」，并补一行「地点与天气随记录保存在本机；查询会联网，不额外保存坐标。」。关于区不得出现账号、云同步或社交入口。

#### Scenario: 查看关于信息

- **WHEN** 用户滚动到设置页底部
- **THEN** 看到品牌名、版本号、「记录仅存本机」，以及地点 / 天气随记录保存、查询会联网但不额外保存坐标的说明

#### Scenario: 没有账号或云同步入口

- **WHEN** 用户浏览关于区
- **THEN** 不出现账号、登录、云同步或社交入口
