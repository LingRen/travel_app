# 记录页地图北向上，朝向由箭头承担

记录页的实时地图不做 heading-up 旋转：底图始终正北朝上，运动方向由地图上的当前位置箭头旋转表达。旋转整张地图会让瓦片文字与指北徽章一起倒转，而记录页地图本就不可交互、取景由轨迹包围盒驱动，旋转会把「重新取景」和「转向」两种运动叠在一起，让人分不清是自己在拐弯还是相机在转。

## 考虑过的选项

- **heading-up（地图随朝向旋转）**：接近车机导航的习惯，但需要给瓦片文字做反向旋转、把取景逻辑拆成「相机朝向」与「轨迹范围」两套，收益不抵代价。
- **只画圆点、不表达朝向**：改动最小，但用户看不出自己是否走反了方向。

## 影响

指北徽章因此永远指北，可以保留；朝向只在箭头这一处表达，不要再引入第二个转向提示。

## 修订（2026-10-28）

反过来改成 heading-up：骑到高速后，北向上时相机只在箭头快出安全区时才大段滑动，看起来一冲一冲的，而且用户更关心「前面往哪拐」而不是正北在哪。现行为：

- 地图按朝向反向旋转（`rotation = -heading`），行进方向始终朝屏幕正上方；
- 旋转带 420ms 补间和 3° 死区，逐秒的 GPS 朝向抖动不会拖着整张图晃；
- 当前位置箭头反向抵消地图旋转，固定朝上，「我在这儿」不再兼表方向；
- heading-up 后相机每一拍都对准当前位置，跟随从「攒够 25% 视口跳一次」改成每 25 米滑一小段；
- 指北徽章跟着盘面转同样的角度，仍然指北；朝向建立前（只有粗定位圆点）维持北向上。

代价仍是当初记录的那条：瓦片文字会跟着倒转。实时页的地图只用作路况参照，可接受。
