# 记录页地图北向上，朝向由箭头承担

记录页的实时地图不做 heading-up 旋转：底图始终正北朝上，运动方向由地图上的当前位置箭头旋转表达。旋转整张地图会让瓦片文字与指北徽章一起倒转，而记录页地图本就不可交互、取景由轨迹包围盒驱动，旋转会把「重新取景」和「转向」两种运动叠在一起，让人分不清是自己在拐弯还是相机在转。

## 考虑过的选项

- **heading-up（地图随朝向旋转）**：接近车机导航的习惯，但需要给瓦片文字做反向旋转、把取景逻辑拆成「相机朝向」与「轨迹范围」两套，收益不抵代价。
- **只画圆点、不表达朝向**：改动最小，但用户看不出自己是否走反了方向。

## 影响

指北徽章因此永远指北，可以保留；朝向只在箭头这一处表达，不要再引入第二个转向提示。
