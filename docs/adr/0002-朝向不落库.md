# 朝向只服务实时箭头，不落库、不进导出

记录页的朝向只用来旋转当前位置箭头，所以只读 `Position.heading` 供当下显示，不写进 `track_points`，也不进 GPX。理由是：GPX 1.1 的 `trkpt` 没有朝向字段，落库要加一列和一次数据库迁移、导出要加私有扩展；而详情页不表达朝向，存下来的值除了调试没有第二个读者。真要回溯，记录页的日志比新列更好用。

## 影响

- `LocationFix` 只多一个用于实时显示的内存字段，`TrackPoint`、`track_points` 表与 GPX 都不加，数据库版本不动。
- 朝向的可信判定与冻结逻辑只活在记录页这一层，历史记录无法「重放」箭头。
- 将来若详情页要画行进方向，必须重算方位角或补一条迁移，届时再判断。
