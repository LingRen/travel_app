# Spec Delta

## Purpose

更新「地图与外观」分组：底图由构建配置决定，普通用户不再编辑瓦片源；主题色选择保持不变。

## REMOVED Requirements

### Requirement: 地图与外观分组提供瓦片源与主题色

**Reason**: 底图改由高德原生地图 SDK 与构建期 Key 决定；瓦片 URL 属于开发配置，不应暴露给普通用户，也无法满足原生样式的纸色外观。

**Migration**: 已存在的 `map_tile_url` 设置值保留在数据库中但不再读取、不再影响底图，也无需用户迁移；升级后该行自动消失。

## ADDED Requirements

### Requirement: 地图与外观分组显示底图状态与主题色

「地图与外观」分组 SHALL 显示一行只读「底图」：配置了高德地图 Key 时显示「高德地图」，未配置时显示「内置栅格底图」。该行 SHALL NOT 提供编辑瓦片 URL 的入口。分组 SHALL 继续提供朱砂、青瓷、黛蓝、藤黄四颗主题色点，主题色点写出名称、当前项带对勾，点击后立即保存并整树重着色。

#### Scenario: 配置了地图 Key

- **WHEN** 用户进入设置页且应用配置了高德地图 Key
- **THEN** 「底图」行显示「高德地图」，点击不打开任何 URL 编辑面板

#### Scenario: 没有地图 Key

- **WHEN** 用户进入设置页且应用没有配置地图 Key
- **THEN** 「底图」行显示「内置栅格底图」，地图仍可正常显示

#### Scenario: 选择青瓷

- **WHEN** 用户点击「青瓷」
- **THEN** 应用立即以青瓷文字安全色渲染选中态，设置行显示「当前 青瓷」，重启后保持

### Requirement: 设置项不暴露开发用的地图地址

设置页 SHALL NOT 显示瓦片 URL、样式文件路径、Key 或任何可编辑的地图服务地址；这些值只通过构建配置、打包资源与本地文件管理。

#### Scenario: 发布构建浏览设置

- **WHEN** 用户浏览发布构建的设置页
- **THEN** 看不到瓦片地址输入、Key 或样式配置
