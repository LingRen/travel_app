# Design

## Context

见 `proposal.md` 的 Why。当前实现是一个 Flutter 3.47 / Riverpod 3 的本地应用，领域层与界面层分离；记录引擎、BLE、落盘、导出与备份已经稳定，`test/domain/**` 覆盖了这些行为。界面层仍是深色沥青主题：`lib/app/theme.dart` 定义深色常量与 Material `ThemeData`，四个 tab 与详情页使用 `AppBar`、`SegmentedButton`、`Card` 与 `NavigationBar`。

设计稿 `design/xingji.pen` 已定稿 9 屏 + 印章组件，是本次视觉与文案的唯一参照。它与现有实现有三处结构性差异：亮色纸本替代深色、五种运动类型替代四种、页眉 / 细线列表替代 Material 组件。另有几项设计稿画了但数据层没有的能力：天气、地点名称、步频 / 步数、真正的高德「宣纸」瓦片；这些不在本次伪造。

约束：

- 数据纯本地，无账号、无云同步、无运行时网络字体。
- 高德栅格瓦片是外部图片，不能改样式文件，只能在客户端做颜色处理。
- 记录引擎与数据库结构尽量不动；类型新增必须兼容已存记录。
- 现有 widget 测试大量断言深色主题、旧标签与 `SegmentedButton` 交互，需要同步改写。

## Goals / Non-Goals

**Goals:**

- 用一套纸本令牌替换深色主题，所有页面共享颜色、字体、间距、圆角与印章。
- 按设计稿重做封面、四个 tab、详情与两个底部面板，保留现有功能与数据流。
- 新增「登山」类型，并把类型选择、锁定与筛选语义在记录、历史、统计、详情中统一。
- 让类型相关的读数（速度 / 配速、功率、踏频、个人最佳）在各页一致。
- 用可测试的组件边界承载版式，避免把颜色和字号散落进页面。

**Non-Goals:**

- 不实现天气、逆地理编码、地点名称、步频、步数或路线规划。
- 不做深色模式、主题切换动画或跟随系统主题。
- 不改记录引擎、GPS 过滤、BLE 协议、数据库 schema 或导出格式。
- 不引入运行时字体下载，不打包完整中文字体。
- 不把高德瓦片替换成自绘地图或自建瓦片服务。
- 不做服务端分页；历史的「更早」是本地内存分组。

## Decisions

### 1. 令牌集中在 `AppPalette`，页面只读语义名

`lib/app/theme.dart` 改为亮色 `ThemeData`，`AppPalette` 从只含 `accent` 扩展为完整色板：`paper`、`sheet`、`ink`、`muted`、`hairline`、`accent`、`accentInk`、`warning`、`danger`。页面通过 `context.palette` 读取，不直接写十六进制。间距与圆角保留现有 `kSpace*` / `kRadius*` 常量并补齐 3 与 18 两档。

替代方案：继续用 `kApp*` 常量并逐页替换。否决，因为主题色是运行时值，常量无法覆盖；两套命名会长期并存。

### 2. 主题色采用「标记色 + 文字安全色」双令牌

设计稿的四种颜料中，青瓷 `#7C9A8B`（对纸底 2.70:1）与藤黄 `#C5A25E`（2.12:1）不能直接做文字或小图标。每种主题因此提供：

| 主题 | 标记色（色点 / 大面积） | 文字安全色（文字 / 图标 / 选中态） |
| --- | --- | --- |
| 朱砂 | `#B4452F` | `#B4452F`（4.82:1） |
| 青瓷 | `#7C9A8B` | `#4F6E60`（4.95:1） |
| 黛蓝 | `#3E5A6B` | `#3E5A6B`（6.42:1） |
| 藤黄 | `#C5A25E` | `#7E5F27`（5.20:1） |

按钮、印章、选中标签、图表线与轨迹使用文字安全色，保证纸底上的对比度；设置页的色点使用标记色，保留颜料本身的观感。按钮填充用文字安全色 + 纸色字，四组都满足 4.5:1。

替代方案一：所有主题都用同一深色强调。否决，失去用户可选的颜料语义。替代方案二：只允许朱砂。否决，设计稿明确给出四色。

### 3. 主题值迁移在读取层完成

`ThemeAccent` 的 `dbValue` 改为 `cinnabar`、`celadon`、`indigo`、`gamboge`。`fromDb` 做只读映射：`mint → celadon`，`sky` / `violet → indigo`，`amber → gamboge`，未知值 → `cinnabar`。不写数据库迁移脚本；用户下次保存设置时自然写成新值。

替代方案：SQL 迁移旧值。否决，设置表只有一行，读取映射更小且可回滚；旧版本读到新值会回退天青，不会崩溃。

### 4. 字体使用平台回退链，不打包中文字体

标题：`Noto Serif SC` → `Songti SC` → `Noto Serif CJK SC` → `serif`；正文：`Noto Sans SC` → `PingFang SC` → `Noto Sans CJK SC` → `sans-serif`；数据：`IBM Plex Mono` → `monospace`，统一启用 `FontFeature.tabularFigures()`。

实时读数（速度、配速、时长、距离跳动值）用等宽数据字体，保证数字宽度不跳；静态大数字（历史距离、详情汇总、统计累计）用衬线显示字体，接近设计稿的 Bodoni 观感。两类样式分开定义，不互相借用。

替代方案一：打包 Noto Serif SC / Noto Sans SC。否决，CJK 字体体积以 MB 计，且本次没有子集化工具链。替代方案二：`google_fonts` 运行时下载。否决，违背离线与本机数据约束。

### 5. 封面是应用内的 `CoverGate`，不是原生启动图

`CyclingApp.home` 改为 `CoverGate(child: RecoveryGate(child: HomeShell()))`。`CoverGate` 在首帧后计时 1.2 秒，点击立即跳过，退场淡出 300ms；`MediaQuery.disableAnimations` 为真时停留 600ms 且不淡出。封面结束后才构建 `RecoveryGate`，保证恢复弹窗出现在封面之后，而不是被盖住。

替代方案一：只做原生启动图。否决，无法呈现品牌文案与跳过交互。替代方案二：封面作为首个路由再替换。否决，返回栈会残留封面。

### 6. 详情在历史 tab 内推入，底部导航保持可见

`HomeShell` 的 `IndexedStack` 中，历史 tab 包一层 `Navigator`；`HistoryPage` 内 `Navigator.of(context).push` 自然落到这层嵌套导航。外层用 `NavigatorPopHandler` 把系统返回转给当前 tab 的导航器。这样详情页保留底部导航并继续标记历史，切换 tab 后返回历史仍停留在详情。

替代方案一：根导航全屏推详情（现状）。实现最省，但设计稿明确保留底栏。替代方案二：在详情页复制一份底栏。否决，双份状态与无障碍语义都容易出错。

### 7. 类型模型只加一个枚举值，能力仍由标志位表达

`ActivityType` 增加 `mountaineering('mountaineering', '登山', usesPace: true)`；保留 `walking`（健走）。`supportsCadence` / `supportsPower` 仍只有骑行打开，`usesPace` 覆盖跑步、健走、徒步、登山。图标与说明抽到 `lib/features/activity/activity_type_visuals.dart`，用穷尽 `switch` 保证新增类型时编译报错而不是运行时缺图标。

替代方案：把 `walking` 改名为登山。否决，会改写已有健走记录的类型语义；用户已选择「新增登山，共五种」。

### 8. 类型选择与筛选做成两组共享组件

- `ActivityTypeChip` + `ActivityTypeSheet`：待机页浮标与五选一面板，当前项朱砂印章 + 对勾；选择后写 `recordController.selectActivityType` 与 `lastActivityType`。
- `SportFilterTrigger` + `SportFilterSheet`：历史 / 统计页的「全部运动 ⌄」与共用面板；选择后只写各自页面的 filter provider。

两个面板共用 `showPaperSheet`（拖动条、标题、副题、关闭、贴底、上方圆角 18、全屏遮罩）。历史与统计的筛选状态保持独立，避免在一个页面筛选后另一个页面悄悄变空。

替代方案：两页共享一个 filter provider。否决，跨页联动不直观，也会让「历史看跑步、统计看全部」这种常见对照无法成立。

### 9. 记录浮层改为纸色渐变 + 墨色字，地图加纸色滤镜

`HandlebarView` 的两条 HUD 渐变由深色改为纸色：顶部 `#F5F0E5` 0.94 → 0，底部 0.96 → 0；文字改为墨色，去掉深色投影。地图瓦片包一层 `ColorFiltered`（降饱和 + 轻微暖色偏移），轨迹仍用 `accentInk`，描边用 `#1D1B17CC`。这样浅色瓦片上墨字可读，深色瓦片上纸色渐变兜底。

地图新增指北与比例尺：指北固定（地图不旋转），比例尺按当前 zoom 与纬度换算米/像素。记录中地图保持 `InteractiveFlag.none`。

替代方案一：保留深色遮罩。否决，与纸本主题冲突。替代方案二：浮层用不透明纸面板。否决，会把全屏地图切成三段。

### 10. 页面版式用共享页眉与细线列表，不再用 AppBar / Card

新增 `lib/app/ui/page_header.dart`（疏排栏目、年月、衬线标题、右侧动作）、`paper_sheet.dart`、`seal.dart`、`paper_button.dart`、`paper_nav_bar.dart`。四个 tab 去掉 `Scaffold.appBar`，页面顶部用 `SafeArea` + `PageHeader`；列表用 1px 发丝线分隔，条目不再包 `Card`。底部导航改为自定义 `PaperNavBar`（58 高、顶部发丝线、图标 20、标签 10、选中用 `accentInk`）。

替代方案：继续用 `NavigationBar` 并改主题。否决，指示器形状、字号与间距无法精确对齐设计稿，且会残留 Material 的选中胶囊。

### 11. 历史按「最近月份 + 更早」在内存分组

`HistoryPage` 先按当前筛选取全部记录，再按 `startedAtMs` 找最近有记录的月份：首屏只渲染该月记录，底部显示「更早的记录 · N 次」；点击后在本地展开剩余记录。筛选变化时重置展开状态。页眉的「二〇二六 · 十月」与本月摘要跟着最近月份与筛选变化。

替代方案一：SQL 分页。否决，本机记录量级小，分页查询与状态管理不值得。替代方案二：一次渲染全部。否决，设计稿的「更早」入口与首屏密度都依赖分组。

### 12. 统计趋势改为柱形，个人最佳按类型选标签

`TrendChart` 从 `LineChart` 改为 `BarChart`：柱色 `accentInk`、顶部圆角 2、柱宽按桶数自适应，纵轴沿用 `niceAxisInterval` 的 1/2/5 序列，横轴标签竖排。触摸提示保留日期桶与两位小数读数。

累计读数改为三项主指标（距离 / 时长 / 爬升）+ 可选功率次级行。个人最佳按编号 01–04 排列；筛选为配速类型时标签为「最快配速」并用 `formatPace`，筛选为骑行或全部时用「最快均速」；功率最佳只在适用时追加。

替代方案：保留折线与六格矩阵。否决，设计稿的柱形与三项主读数更符合「一页看完」的目标；功率仍以次级行保留，不丢功能。

### 13. 设置改为行 + 底部编辑面板，即时保存

`SettingsPage` 的身体参数与瓦片源改为「标签 + 当前值」行；点击行打开 `showPaperSheet`，面板内输入、校验、确认后立即写库。距离单位在行内用两枚纸本 chip 切换。主题色点仍即时保存。传感器与备份保留现有行为，只换版式。关于区显示「行迹 XINGJI · 1.0.0」「数据仅存本机」。

替代方案：保留 TextField + 全局「保存」。否决，设计稿没有保存按钮，且全局保存会让主题色与输入项的提交语义分裂。

### 14. 测试分三层，视觉靠组件测试与真机截图

- 纯逻辑：主题迁移、对比度、类型能力、历史分组、统计口径，继续用 `flutter_test`。
- 组件：封面时序、纸本 HUD 对比、类型面板、筛选面板、历史展开、设置编辑面板、详情类型分支。
- 真机：390×844 与 360×640 截图，文字缩放 1.3，户外强光下读速度。

不做 golden 测试：中文字体回退在不同平台不一致，golden 会长期红。改用关键布局断言（无溢出、地图带高度、控件可见）与人工截图。

## Risks / Trade-offs

- **纸本主题在户外强光下不如深色** → 墨色对纸底 15:1，HUD 加纸色渐变；真机户外验收速度与距离读数，必要时加深渐变不透明度。
- **高德瓦片加滤镜后仍可能偏花** → 先降饱和 0.55 + 暖色偏移，真机调参；滤镜只包 `TileLayer`，不影响轨迹与文字。
- **青瓷 / 藤黄作为文字对比不足** → 双令牌强制文字走 `accentInk`；主题测试逐色守 4.5:1。
- **字体回退在 Android 上可能没有中文衬线** → 标题仍能回退到系统 sans，版式不崩；后续可单独做字体子集化，不在本次范围。
- **嵌套导航的返回与测试复杂度** → 用 `NavigatorPopHandler`，补系统返回与 tab 切换测试；若实现成本超预期，退回根导航全屏详情并在设计文档记录偏差。
- **新增枚举导致 switch 不穷尽** → 图标、说明、统计分支全部用穷尽 `switch`，编译器兜底。
- **历史分组在「本月无记录」时页眉月份错位** → 取最近有记录的月份；完全无记录时显示空态，不渲染月份摘要。
- **统计柱形在桶很多时拥挤** → 年视图按月 12 桶、周视图 7 桶、月视图 4–5 桶；柱宽自适应，标签竖排；必要时横向滚动。
- **设置即时保存的失败处理** → 先写库成功再更新界面；失败保留面板并显示错误，不假装成功。
- **一次性替换全部页面导致回归面过大** → 按令牌 → 外壳 → 类型 → 记录 → 回顾 → 统计 → 设置分阶段提交，每阶段跑现有测试；领域层不动。

## Migration Plan

1. **令牌与主题**：替换 `theme.dart`，新增双令牌与迁移映射，更新主题测试；此阶段页面仍可用旧组件，但颜色已切换。
2. **外壳**：`CoverGate`、`PaperNavBar`、`PageHeader`、`PaperSheet`、`Seal`；接入 `HomeShell` 与嵌套导航。
3. **类型**：新增 `mountaineering`，抽图标 / 说明，补类型面板与筛选面板；记录页接入选型浮标。
4. **记录**：纸本 HUD、地图滤镜、指北 / 比例尺、动作区与结算页。
5. **回顾**：历史页分组与条目、详情页版式与类型分支。
6. **统计**：页眉、三项主读数、柱形趋势、个人最佳。
7. **设置与平台**：行式编辑、四主题色、关于区；Android / iOS 显示名与状态栏。
8. **收尾**：更新 README 与旧设计文档中的主题 / 类型描述，跑全量测试与真机截图。

回滚：按阶段 revert 对应提交即可；数据层只新增枚举值与读取映射，旧版本读到新主题值会回退天青，读到 `mountaineering` 会回退骑行展示，不丢记录。发布前在真机确认一次升级路径（旧库 → 新版本）。

## Open Questions

- 是否在后续版本打包 Noto Serif SC 子集，以消除 Android 衬线回退差异。可延后，不影响本次版式与规格。
- 地图纸色滤镜的具体矩阵与比例尺精度需要在真机上调；参数可改，不改变交互与规格。
- 未来是否接入天气与地点数据；本次明确不展示无来源信息。
