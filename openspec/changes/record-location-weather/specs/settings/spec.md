# Spec Delta

## Purpose

更新设置页关于区，让用户知道运动记录仍只存本机，但待机页的位置名称与天气查询会联网，坐标不会被保存。

## MODIFIED Requirements

### Requirement: 关于分组声明品牌与本机属性

设置页底部 SHALL 显示「行迹 XINGJI · 1.0.0」与「记录仅存本机」，并补一行「位置名称与天气查询会联网，坐标不落库。」。关于区不得出现账号、云同步或社交入口。

#### Scenario: 查看关于信息

- **WHEN** 用户滚动到设置页底部
- **THEN** 看到品牌名、版本号、「记录仅存本机」，以及位置 / 天气查询会联网、坐标不落库的说明

#### Scenario: 没有账号或云同步入口

- **WHEN** 用户浏览关于区
- **THEN** 不出现账号、登录、云同步或社交入口
