# Spec Delta

## Purpose

把定位源切换限制在调试构建，发布构建不出现未验收的采集路径。

## MODIFIED Requirements

### Requirement: 调试工具只在调试构建出现

开发用的模拟数据、调试入口与定位源切换 SHALL 只在调试构建显示，发布构建不得出现。定位源行 SHALL 显示当前选择（系统定位 / 高德定位），仅在待机状态可切换，记录中或暂停时不可用。

#### Scenario: 发布构建

- **WHEN** 以 release 模式启动应用
- **THEN** 设置页不显示调试分组，也不显示定位源切换

#### Scenario: 调试构建切换定位源

- **WHEN** 调试构建在待机页打开设置并把定位源改为「高德定位」
- **THEN** 该选择持久化，下一次开始记录时生效，设置行显示当前选择

#### Scenario: 记录中不可切换

- **WHEN** 记录正在运行或暂停
- **THEN** 定位源行置灰或不可点击，并说明需结束本次记录后切换
