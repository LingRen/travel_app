# Spec Delta

## Purpose

说明定位源切换只影响采集实现，不改变记录状态、断点与读数语义。

## ADDED Requirements

### Requirement: 定位源切换不改变记录状态语义

记录页 SHALL 继续以「最近一次可信定位点」的时间判定信号状态，不得因定位源是高德或系统而改变判定口径。断点阈值、距离 / 爬升算法、轨迹抽稀与 GPX 结构 SHALL 保持不变。

#### Scenario: 高德源信号弱

- **WHEN** 使用高德定位且超过 10 秒没有可信定位点
- **THEN** 状态显示「信号弱」，与系统定位同一判定

#### Scenario: 切换后开始记录

- **WHEN** 用户在待机页把定位源从系统切到高德并按下开始
- **THEN** 记录从高德流取点，界面读数、断点与结束结算行为不变

#### Scenario: 记录中禁止切换

- **WHEN** 记录处于进行中或暂停状态
- **THEN** 设置页的定位源切换不可用，避免两套定位流同时存在
